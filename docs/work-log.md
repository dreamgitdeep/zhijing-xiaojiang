## 一、项目概述

**植景小匠**是面向《植物造景》课程的教学网页应用，服务学生自学与教师教学管理两条主线：

- **学生端**：植物图鉴（135 种植物 + 810 道练习题，筛选/卡片/详情）、练习与掌握判定（错题订正制）、AI 智能问答（SSE 流式 + 语音输入/播报）、学习管理数据大屏、消息通知、植景设计实训（六阶段案例任务 + 规则/AI 双轨评阅）。
- **教师端**：概览统计、植物数据管理（两栏主从编辑 + 图片上传 + 智能识别）、学情看板（班级管理 + 导出 + AI 学情分析）、设计任务发布与评阅管理、提醒未完成学生。

数据双模式：配置 Supabase 环境变量走云端，否则降级 local（plants.json + localStorage）。当前运行环境已接 Supabase 云端。

- **实现**：新增通话引擎 `src/components/design/use-voice-call.ts`（半双工状态机：AI 播报完自动开麦 → 学生说话 → 停顿 1200ms 自动发送 → AI 思考/逐句播报 → 循环；播报期间麦克风恒关防 TTS 回声；Chrome 连续识别自动重连；挂断即停识别+停播报）。`StageDiagnosis` 删输入框/发送/旧录音按钮，空闲态 = 通话记录 + 「接通顾问语音」按钮，通话中 = 通话屏（头像呼吸环/阶段文案/计时/实时字幕）+ 静音/挂断；首次接通问候语入记录，再接通只播不写。
- **不变**：/api/design/chat SSE、问询命中（newHits）、提问计数、S1 评阅打分链路零改动；对话记录仍走既有 localStorage 持久化。
- **边界**：半双工不支持抢话；需 Chrome/Edge + 联网识别；不支持浏览器显示警示文案；无 TTS 时字幕兜底。
- **验收**：生产构建通过、页面 200、通话 UI 进客户端产物、未登录接口 401 守卫正常；真实麦克风 + TTS 通话需真机浏览器确认（沙箱无音频设备）。

### 迭代 46 · 语音通话上云（自然音色 + 云端识别）+ 每日通话配额（2026-10-14，教师点名）

- **需求**：① 音色太死板，要拟人有语气；② 浏览器识别听不到学生说话、不灵敏；③ 云端语音成本顾虑 → 每生每日通话配额护栏，**超额降级为文字/浏览器语音输入**。
- **实现**：
  - 新增登录守卫路由 `/api/voice/tts`（≤500 字 → audio/mpeg 字节，音色 `zh_female_vv_uranus_bigtts`）、`/api/voice/asr`（base64 WAV → 文本）、`/api/voice/session`（配额闸门，`QUOTA_CALLS_PER_DAY = 5`）。
  - 新建表 `voice_usage(user_id, usage_date, call_count)`（PK 复合、RLS 开启、仅 service role 读写），按北京时间当日计数。
  - `use-voice-call.ts` 重写为云端引擎：分句合成 + **下一句预取** + `<audio>` 顺序播放；录音侧 `AnalyserNode` 能量 VAD（环境底噪自适应阈值、静音 900ms 判句、单句 30s 上限）→ 16kHz WAV → 云端识别；播报期间录音恒关防回声；单通 15 分钟自动挂断。
  - `StageDiagnosis`：接通前先过配额闸门；超额 → 底部降级文字输入 + 浏览器语音输入 + 发送（不走云端播报）；麦克风权限被拒出提示。
- **成本口径**：LLM Token 零新增（问答链路与原文字模式等量）；新增仅 TTS 按字数、ASR 按时长；护栏 = 每生每日 5 通 + 单通 15 分钟 + 载荷上限。
- **验收**：`scripts/voice_smoke_test.ts` 全绿（配额 5 允 1 拒 → TTS 返 29KB 音频 → 同音频回传 ASR 原文识别 → 测试账号与孤儿行清理）；生产构建通过、页面 200、三路由未登录 401。
